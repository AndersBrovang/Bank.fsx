# F# Bank Account Demo (.fsx)

Previous assignment where I had to build a simple functional banking system in F#, focusing on pure functions, immutability, and basic list operations.

## Overview

This script models checking and saving accounts using tuples and lists.  
It includes basic banking operations like deposits, withdrawals, transfers, and applying interest.  
Everything is done in a purely functional style, without using types or modules (as required by the assignment).

## Features

- Add or withdraw money from checking and saving accounts  
- Transfer between saving and checking accounts  
- Apply interest to all saving accounts for all customers  
- Uses only lists, tuples, recursion, and higher-order functions  

## How to Run

You can run the script directly with F# Interactive:

```bash
dotnet fsi Bank.fsx
